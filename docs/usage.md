# Інструкція запуску агента та локальної перевірки

## Запуск AI-агента у VS Code Copilot Chat
- Оберіть агента `@build-engineer`.
- Виконайте `/init` для повного циклу ініціалізації, створення проєкту, збірки, CI та перевірки.
- Виконайте `/check` для перевірки стану проєкту в режимі «тільки читання».
